# Expense Tracker

A simple yet powerful React application to track your expenses with filtering capabilities.


##  Features
- Add new expenses with name, amount, date, category, and description
-  Filter expenses by name or description
-  Date picker for expense entries
-  Tabular display of all expenses
-  Built with React and Vite
-  Published Through Vercel

##  Getting Started

### Prerequisites
- Node.js (v14+)
- npm (v6+)

### Installation
```bash
git clone https://github.com/NevilleM23e/expense-tracker-code-challenge
cd expense-tracker-code-challenge
npm install
npm run dev
```
